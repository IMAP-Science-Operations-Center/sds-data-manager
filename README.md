# SDS-data-manager

This project is the core of a Science Data System.

Our goal with the project is that users will only need to modify the file config.json to define the data products stored on the SDS, and the rest should be mission agnostic.

## Requirements

- AWS CLI [download link](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html)
- nodejs [download link](https://nodejs.org/en/download/)
- Docker [download link](https://docs.docker.com/get-docker/)

## Development

For information on setting up and installing Poetry, check out our [getting started](https://imap-processing.readthedocs.io/en/latest/development/getting-started.html) documentation.

Additional documenation on setup and development in this repo can be found in the [infrastructure](https://imap-processing.readthedocs.io/en/latest/infrastructure/index.html)
section of our documentation.

## API Access

Our API can be accessed through the [imap-data-access](https://github.com/IMAP-Science-Operations-Center/imap-data-access) library. We have [additional documentation](https://imap-processing.readthedocs.io/en/latest/data-access/index.html) available for HTTPS access.
